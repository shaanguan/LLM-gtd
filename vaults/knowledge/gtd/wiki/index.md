# GTD 知识库索引

本知识库基于 David Allen 的 Getting Things Done 方法论，提供核心概念的结构化解释，帮助你理解和运用 GTD 系统。

## 核心工作流

| 页面 | 摘要 |
|------|------|
| [[inbox-processing\|收集箱处理]] | 从入口到分流的决策树：能行动吗→两分钟能搞定吗→委托还是延迟 |
| [[weekly-review\|周回顾]] | 每周一次的系统维护仪式，确保清单完整、项目推进、承诺不遗漏 |

## 核心清单

| 页面 | 摘要 |
|------|------|
| [[next-action\|下一步行动]] | 项目当前可见的、物理上可执行的最小动作单元 |
| [[project-definition\|项目定义]] | 任何需要两步以上才能达成的预期结果，无论大小 |
| [[someday-maybe\|将来/也许]] | 暂不行动但不愿丢弃的想法暂存区，周回顾时定期审视 |
| [[waiting-for\|等待清单]] | 已委托他人的事项追踪：等谁、等什么、何时委托 |

## 执行策略

| 页面 | 摘要 |
|------|------|
| [[context-labels\|情境标签]] | 按当前环境（电脑/手机/外出/低能量）筛选可执行动作 |
| [[two-minute-rule\|两分钟规则]] | 处理收集箱时，能在两分钟内完成的事立刻执行不记录 |
| [[energy-management\|精力管理]] | 根据当前精力水平选择匹配难度的任务，而非死守优先级 |

## 系统维护

| 页面 | 摘要 |
|------|------|
| [[natural-planning\|自然计划法]] | 五步规划：目的→愿景→头脑风暴→组织→下一步行动 |
| [[reference-system|参考资料系统]] | 不需要行动但有保存价值的信息的归档与检索结构 |
