LLM-GTD Quick Start

这是 setup 自动弹出的第一屏。你不需要懂 GTD：你的 AI GTD 高级秘书会把自然语言整理成可信系统。

GTD 五阶段 × LLM-GTD
收集 对 Agent 说话 / 粘贴清单 / 导入材料 / 使用已启用的捕获入口 厘清 Agent 像 GTD 高手一样理解意图、拆分行动、识别等待和项目，你只需确认或纠正 组织 归档到正确目录、填写元数据，并在有 provider 时刷新对应视图 回顾 早间播报 / 晚间回顾 / 周回顾 — 说一句话触发 执行 从 vault 证据选择下一步；已启用的视图或消息会作为辅助投影
日常操作
📥 捕获想法
随时对你的 GTD Agent 说：加到 GTD：明天跟前端对齐动效方案
如果你启用了捕获 provider，也可以从对应入口把内容送入 Inbox。
🧹 处理收件箱
说 帮我过一下 Inbox，逐条按 GTD 决策树分拣：
→ 2 分钟能做？立刻做掉
→ 下一步是什么？→ Next Actions
→ 交给别人？→ Waiting For
→ 以后再说？→ Someday Maybe
🎯 看今天做什么
说 今天做什么，列出不超过 3 条 MIT（Most Important Tasks）。
📁 管理项目
说 新建项目：App 首页改版，自动创建项目文件并关联下一步行动。
✅ 完成任务
说 xxx 做完了，自动归档到 06 - Archive 并记录成就。
🧭 确认自动化
setup 完成后会生成 .llm-gtd/setup-report.md。里面能看到 core vault、Agent instructions、以及已选择 provider 的状态。
如果某个 provider 是后续启用的，再用对应 provider 的 verify 命令检查。
日常节奏（说一句话触发）
说 "早" 早间播报：今日 MIT + 临近截止 + 等待回复提醒 说 "回顾" 晚间回顾：批量确认完成项、处理新 Inbox、更新周报 说 "周回顾" 完整周回顾：7 步清理，确保系统不腐化 可选 provider 渲染视图、备份、消息、在线文档或调度能力按需启用
你的系统
📂 Vault
所有事实都在本地 Markdown vault 里：Inbox、Projects、Next Actions、Waiting For、Reference、Archive、Achievements。
Agent 回答状态问题前会从这些文件取证。
🧩 Providers
捕获、渲染、调度、消息、在线文档、备份都属于可选 provider。没有启用 provider 时，GTD 仍然通过 vault + Agent 对话正常工作。
📋 排期表
同事看到的你的交付排期。只展示有独立交付物的事项，自动从 vault 同步。
点击打开飞书/钉钉文档
📝 每日安排
你的每日工作简报。今日 MIT + 明日预览 + 历史记录，同事一眼看出你忙不忙。
点击打开飞书/钉钉文档
第一步建议：回到对话，把脑子里飘着的待办/承诺/想法一条条倒给 Agent。说 加到 GTD：xxx 就行。积攒几条后说 帮我过一下 Inbox 开始分拣。
