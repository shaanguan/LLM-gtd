# Desktop Workspace Profile

Use this profile when the GTD vault is the current workspace, or when the Agent can directly read `AGENTS.md` / `CLAUDE.md` and the vault folders.

## Contract

- Treat workspace instructions as authoritative after reading `AGENTS.md` or `CLAUDE.md`.
- Use full-vault evidence for status, review, prioritization, and cleanup.
- Prefer batch edits and structured vault maintenance when the user asks for review, sweep, or organization.
- Discover local providers before scriptable work. Use doctor, setup/upgrade/uninstall, and provider-specific verification only when the provider exists.

## Capture

Because the workspace itself is the GTD vault, ordinary work/task capture can proceed with fewer clarifications than `remote-im`.

Still ask before writing when the user explicitly frames the note as memory, wiki knowledge, unrelated project notes, or another workspace's data.

## Review And Editing

- For `早`, `回顾`, and `周回顾`, scan the vault before answering.
- For Inbox sweeps, propose moves and frontmatter changes; ask for confirmation before destructive archive or completion actions.
- After vault changes, refresh discovered render/projection providers.

## Runtime Duties

Desktop workspace can verify local files and local providers well. Remote scheduler jobs, messaging credentials, webhooks, bots, and online docs are cleaned up through matching connector tools.
