LLM-GTD Quick Start

这是 setup 自动弹出的第一屏。你不需要懂 GTD：你的 AI GTD 高级秘书会把自然语言整理成可信系统。

GTD 五阶段 × LLM-GTD
收集 快捷键 ⌘I / 对 Agent 说话 / IM 上给助手发消息 厘清 Agent 像 GTD 高手一样理解意图、拆分行动、识别等待和项目，你只需确认或纠正 组织 自动归档到正确目录、填写元数据、刷新 Dashboard 回顾 早间播报 / 晚间回顾 / 周回顾 — 说一句话触发 执行 Dashboard 一页看全，排期表告诉同事你在做什么
日常操作
📥 捕获想法
随时对你的 GTD Agent 说：帮我记：明天跟前端对齐动效方案
macOS 用户也可以按 ⌘ I 唤出全局捕获面板，输入后回车即保存。
🧹 处理收件箱
说 帮我过一下 Inbox，逐条按 GTD 决策树分拣：
→ 2 分钟能做？立刻做掉
→ 下一步是什么？→ Next Actions
→ 交给别人？→ Waiting For
→ 以后再说？→ Someday Maybe
🎯 看今天做什么
说 今天做什么，列出不超过 3 条 MIT（Most Important Tasks）。
📁 管理项目
说 新建项目：App 首页改版，自动创建项目文件并关联下一步行动。
✅ 完成任务
说 xxx 做完了，自动归档到 06 - Archive 并记录成就。
日常节奏（说一句话触发）
说 "早" 早间播报：今日 MIT + 临近截止 + 等待回复提醒 说 "回顾" 晚间回顾：批量确认完成项、处理新 Inbox、更新周报 说 "周回顾" 完整周回顾：7 步清理，确保系统不腐化 自动 Dashboard 每 30 分钟刷新 / git 每晚 23:55 快照
你的工具
📊 Dashboard
你的 GTD 指挥中心。一页看清：今日重点、逾期项、等待回复、活跃项目。
点击打开 → 建议收藏到浏览器书签栏
📋 排期表
同事看到的你的交付排期。只展示有独立交付物的事项，自动从 vault 同步。
点击打开飞书/钉钉文档
📝 每日安排
你的每日工作简报。今日 MIT + 明日预览 + 历史记录，同事一眼看出你忙不忙。
点击打开飞书/钉钉文档
第一步建议：先点上面的 Dashboard 看看（目前是空的，正常）。然后回到对话，把脑子里飘着的待办/承诺/想法一条条倒给它。说"帮我记：xxx"就行。积攒几条后说"帮我过一下 Inbox"开始分拣——Dashboard 会实时刷新。
