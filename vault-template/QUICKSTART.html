LLM-GTD Quick Start

你的 AI GTD 秘书已就位。5 件事让你上手。

日常操作
📥 捕获想法
随时对 QoderWork 说：帮我记：明天跟前端对齐动效方案
macOS 用户也可以按 ⌘ I 唤出全局捕获面板，输入后回车即保存。
🧹 处理收件箱
说 帮我过一下 Inbox，逐条按 GTD 决策树分拣：
→ 2 分钟能做？立刻做掉
→ 下一步是什么？→ Next Actions
→ 交给别人？→ Waiting For
→ 以后再说？→ Someday Maybe
🎯 看今天做什么
说 今天做什么，列出不超过 3 条 MIT（Most Important Tasks）。
📁 管理项目
说 新建项目：App 首页改版，自动创建项目文件并关联下一步行动。
✅ 完成任务
说 xxx 做完了，自动归档到 06 - Archive 并记录成就。
自动节奏（不用你操心）
每天早上 推送播报：今日 MIT + 临近截止 + 等待回复提醒 每天晚上 找你回顾：确认完成项、处理新 Inbox、更新周报 每周日 完整周回顾：7 步清理，确保系统不腐化 每天 23:55 静默 git commit，留底可回滚
第一步建议：现在回到 QoderWork，把脑子里飘着的待办/承诺/想法一条条倒给它。说"帮我记：xxx"就行。积攒几条后说"帮我过一下 Inbox"开始分拣。
