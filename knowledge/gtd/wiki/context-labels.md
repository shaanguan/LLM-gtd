# 情境标签（Context）

情境（Context）是 GTD 组织体系中的关键概念，用来对下一步行动进行分类和筛选。它回答的核心问题是：**在什么时候、什么地点，你可以做什么？**

## 什么是情境

在 GTD 中，情境指的是执行行动时所需的外部条件——你所在的位置、可用的工具、可用的时间和精力。每个行动都有其特定的情境要求，脱离了情境的行动是无法执行的。

例如，"给张三打电话"这个行动只能在有电话的情境下完成；"写项目报告"只能在有电脑的情境下完成。

## 常见的情境标签

GTD 通常使用 `@` 符号来标记情境：

**按地点：**
- `@办公室` -- 需要在办公室完成的事
- `@家里` -- 需要在家完成的事
- `@外出` / `@商场` -- 需要外出完成的事

**按工具：**
- `@电话` -- 需要用电话完成的事
- `@电脑` -- 需要用电脑完成的事
- `@邮件` -- 需要通过邮件处理的事

**按时间/精力：**
- `@高精力` -- 需要深度思考的任务
- `@低精力` -- 机械性、低消耗的任务
- `@15分钟` -- 可以在15分钟内完成的碎片任务

## 为什么情境很重要

情境是 GTD 选择当前行动的四个标准中的第一个（也是最重要的）：

1. **情境** -- 你现在在哪里？有哪些工具可用？
2. **可用时间** -- 你现在有多少时间？
3. **精力水平** -- 你现在的精力如何？
4. **优先级** -- 在以上条件都满足时，选最重要的

使用情境标签后，你可以在特定环境下快速筛选出合适的任务列表，而不是面对一个冗长的通用清单无从选择。比如你在打电话的时候，只需要看 `@电话` 清单，从中选择接下来要打哪个电话。

## 实践中的建议

一位 GTD 实践者分享了自己的标签分类方法：按地点（如自习室、宿舍、电脑旁）、需要的时间、需要的精力或集中力、所属的工作、重要性。使用标签对行动进行分类后，使用过滤器为不同的场合和情况筛选出合适的任务列表。

**关键在于不要过度分类：** 情境标签的目的是帮你在正确的场景下找到正确的事，而不是创建一个复杂的分类系统。如果你的工作场景简单，2-3个情境标签就足够了。

## 与 ZTD 的区别

[[ztd-overview|ZTD]] 对情境的态度更简化——它认为大多数人的工作场景比较固定，不需要过多的情境标签。ZTD 更强调通过 MIT（最重要的任务）来确定优先级，而非通过情境来筛选行动。
