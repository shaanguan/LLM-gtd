# Dashboard Plugin

Optional vault visualization plugin.

Current compatibility entrypoints:

- `tools/plugins/dashboard/vault-assets/Dashboard.html`
- `tools/plugins/dashboard/vault-assets/export_dashboard.py`
- `tools/setup/create_app.py`

This plugin must not be treated as LLM-GTD core. It can visualize a GTD vault or another vault-like system when pointed at a compatible data source.
